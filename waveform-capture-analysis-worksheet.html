Student Information

Objectives: Connect a scope safely and correctly; choose the right trigger and capture mode for the event; use cursors, zoom and reference waveforms; recognize common waveform faults; capture, measure and judge a real signal against spec.

Capture Workflow read before you start

  1. Look it up first. Find the wiring diagram, connector pin, wire color and expected signal in Service Express / iN.
  2. Ground the scope lead to battery negative or a clean engine ground.
  3. Back-probe the signal terminal with the connector plugged in. Don't pierce the insulation.
  4. Set vertical: pick a V/div that keeps the whole expected signal on screen. Use DC coupling for most sensor work.
  5. Set horizontal: pick a time/div that shows several cycles at the test RPM, and set the record length.
  6. Set the trigger: source, a level inside the signal's range, slope, then the mode (Auto, Normal or Single).
  7. Run the test condition (key on, crank, idle, snap throttle, wiggle test) and capture.
  8. Freeze, save and analyze: measure with cursors, zoom in on suspect areas, and compare against spec and a known-good reference.
Safety: Route leads away from belts, fans and exhaust. Never connect the scope directly to ignition secondary voltage. Use only a rated secondary pickup or attenuator. Check the probe ratio setting every time you add an attenuator.

With instructor approval, capture one sensor or actuator signal on a shop vehicle. Record your setup and measurements, then judge the signal against spec or a known-good capture. Save the capture on the scope and show it to your instructor.
Instructor scoring

Capture: 2 = safe hookup, a stable capture shown to the instructor, all setup and measurement fields filled in · 1 = capture made but setup or measurements incomplete · 0 = no capture.
Analysis: 2 = correct good/faulty call backed by measurements and the spec · 1 = call made with weak or missing support · 0 = no conclusion.
