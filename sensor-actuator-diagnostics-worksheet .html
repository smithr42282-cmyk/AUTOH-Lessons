Quick Reference read before you start

Sensors

  • 3-wire sensors (TP, APP, MAP, many position sensors): 5 V reference in, sensor ground out, signal back to the ECM.
  • NTC thermistor (ECT, IAT): 2 wires. Resistance drops as temperature rises, so signal voltage drops as the engine warms.
  • Potentiometer (TP, APP): the signal should rise smoothly through the sweep. Any sudden spike or drop points to a worn spot in the track.
  • Hall / MRE digital sensors: square wave, usually 0–5 V. Variable reluctance (magnetic): AC sine wave whose amplitude grows with speed.

Actuators & strategy

  • Ground-side control: the solenoid has power all the time, and the ECM switches the ground. On the scope, low (near 0 V) = ON.
  • PWM: fixed frequency, variable duty cycle. A higher on-time % means more flow or more movement.
  • Fault splitting: if the signal is lost while the 5 V reference stays steady, suspect the sensor or its signal wire. If the reference drops at the same moment, the fault is upstream (wiring, terminal, or ECM supply).
  • Grounds: voltage-drop test the sensor ground with the circuit working: back-pin the sensor ground, put the lead's ground on battery negative, and read the average with a Signal ruler or Measurements.
Honda/Acura note: Look up circuits, pin numbers and specs in Service Express / iN. Compare what the scope shows with the HDS data list. Where the HDS can command an actuator, use it to watch the ECM's command change on the scope.

PicoScope 4225A setup for these tests

Two-channel hookupTA404 blue lead → Channel A, TA405 red lead → Channel B, each into a TA161/TA162 flexible back-pinning probe. Put both leads' grounds on battery negative with the TA158 clip. Turn on ConnectDetect to confirm both channel LEDs show green before you run.
Sweep tests (TP / APP)Use a slow Timebase (200 ms/div or slower) and a Single trigger so one capture holds the whole sweep. Then use Windowed Zoom to inspect any glitch.
PWM actuatorsAdd Measurements → Frequency and Duty cycle for the channel, and check them against your own ruler readings. On a ground-side driver, the low part of the waveform is the on-time.
Separating tracesUse Scale & Offset in each channel's Channel options to move Channel A and Channel B apart on the screen so the traces don't overlap. Each channel keeps its own axis.
Wiggle testsSet Repeat or Single with the trigger threshold just below normal (Falling), flex the harness, then review every capture in the Waveform Buffer.
